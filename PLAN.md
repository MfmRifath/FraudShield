- [x] `SparkovAdapter` (CC0): uid = cc_num (tested on the real fixture; full dataset built)
- [x] `make data`: Kaggle download + data manifest (file sha256, size, row counts) in `data/manifests/<ds>.raw.json` (Sparkov, anonymous download)
- [ ] `make data DATASET=ieee_cis` + `make features DATASET=ieee_cis` on real data (**blocked: needs user's Kaggle token + accepted competition rules**)
- [x] pandera schemas at the adapter output
- [x] `features/definitions.py`: single source of feature definitions
- [x] `features/offline.py`: Polars/DuckDB, time-ordered, PIT (strictly-prior events + current event; target encodings use only labels available at the daily snapshot, ADR-0005)
- [x] All feature families from the spec (request-only, velocity, amount aggregates, ratios, recency, distinct counts, first-seen flags, target encodings): 48 features on Sparkov
- [x] `training/splits.py`: time splits with 7-day gaps + rolling-origin CV
- [x] Committed Sparkov fixture (2,000 raw rows, CC0) generated by `make fixture`
- [x] EDA notebook (imports the package only), executed on Sparkov
- [x] Hypothesis no-future-leakage property tests; split-gap tests; brute-force oracle equivalence

## Phase 2: Modeling

- [ ] Baselines: rules-only, logistic regression, LightGBM request-only ("degraded"), LightGBM full
- [ ] Optuna tuning (time-aware CV, `scale_pos_weight` searched, no SMOTE)
- [ ] Calibration: isotonic on val; Platt if positives < 1000
- [ ] `configs/costs.yaml` + cost policy (min expected cost, daily review capacity)
- [ ] Evaluation: PR-AUC, ROC-AUC, recall@FPR {0.1, 0.5, 1}%, Card Precision@100/day, Brier, ECE + reliability plot, dollar outcomes vs rules-only and approve-all, new vs known uid, cost sensitivity sweep
- [ ] Reason-code map (feature family -> template)
- [ ] MLflow logging (params, git sha, data manifest hash, feature list hash, plots)
- [ ] pyfunc package (booster + calibrator + feature order + policy + reason map); register; alias `@challenger`
- [ ] `model_card.py` -> `docs/model_card.md`
- [ ] Training smoke test (10k rows, 20 trees)

**DoD:** comparison table and plots generated by a script; test-window dollar savings and Card Precision@100 reported; model card generated.

## Phase 3: Serving

- [ ] Canary routing by `hash(uid) % 100 < canary_pct`
- [ ] Prometheus metrics per spec
- [ ] Dockerfile (multi-stage, non-root, arm64 + amd64)
- [ ] In-process latency benchmark script
- [ ] Contract + fallback tests

**DoD:** contract + fallback tests pass; in-process p95 < 20 ms reported by the benchmark.
